# Gronxity
Gronxity is a full-stack job portal connecting students, job seekers, and recruiters. It includes job posting, applications, messaging, courses, AI-based ranking, smart job matching, profiles, and large-scale connectivity. Built with React.js, Node.js, Express.js, and MongoDB, it provides an efficient platform for career growth and recruitment.
